OWASP Frontend Lab — Installation Free

This is the Option A package: pure HTML+JavaScript simulations of SQLi, XSS, CSRF, LFI and security headers.

SQL Injection XSS (Stored & Reflected) CSRF File Inclusion Burp Suite (Sim) Security Headers (Sim) Security Report (PDF)

Quick start

  1. Double-click index.html to open this lab in your browser.
  2. Use each page to simulate an attack and then click the Mitigation panels.
  3. All data is stored in your browser (localStorage) and never leaves your machine.

Warning: These pages intentionally demonstrate insecure behavior — only run locally on your own machine.
